This repository demonstrates the usage of DestinE Safe@Sea forecast produced by Norwegian Meteorological Institute and the Finnish Meteorological Institute under a contract with ECMWF and funded by the EU.

Safe@Sea provides 2 day wave and vessel icing forecast on a daily basis. It uses the DestinE Extremes DT 4 km global forecast system as boundary/surface forcing​ and produces the data at 1 km resolution over the Barents Sea. Data is available from Dec 2025, and this repository demonstrates the basic data access and shows how to work with the data.​
